# Sina Doctor Booking - افزونه نوبت دهی پزشکان سینا

سیستم کامل نوبت‌دهی پزشکان با پنل بیمار، منشی و مدیر - طراحی شده برای وردپرس با قابلیت اتصال به ووکامرس و المنتور و پرینت حرارتی

## ✨ ویژگی‌ها

### 🧑‍⚕️ برای بیماران
- **صفحه اول:** لیست پزشکان با تخصص، بیوگرافی و هزینه ویزیت
- **انتخاب روز:** نمایش روزهای دارای نوبت خالی با تقویم شمسی
- **انتخاب ساعت:** اسلات‌های 15 دقیقه‌ای (قابل تنظیم) با نمایش وضعیت (خالی/رزرو/مسدود)
- **ثبت اطلاعات:** نام، موبایل، کد ملی، سن، جنسیت و توضیحات
- **پرداخت بیعانه:** مبلغ ناچیز (مثلا 5,000 تومان) برای تایید رزرو - با ووکامرس یا بدون
- **کد رهگیری:** صدور کد یکتا SINA-XXXXXX و نمایش رسید قابل چاپ
- **پیگیری نوبت:** جستجو با کد رهگیری
- **پنل بیمار:** مشاهده تمام نوبت‌ها، وضعیت، چاپ رسید

### 👩‍💼 برای منشی / مدیر
- **پنل منشی:** `[sina_secretary_panel]` - فیلتر بر اساس پزشک، تاریخ، وضعیت، جستجو
- **ویرایش نوبت:** تغییر وضعیت (در انتظار/تایید/ویزیت/لغو)، تاریخ ویزیت واقعی
- **محاسبه خودکار هزینه:** انتخاب خدمات (نوار قلب، سونوگرافی...) + ویزیت = جمع کل
- **مدیریت پرداخت:** ثبت مبلغ پرداختی، وضعیت پرداخت
- **حذف/اضافه نوبت:** امکان بستن اسلات یا حذف نوبت
- **چاپ:** رسید حرارتی 80mm و A4 برای بیمار + لیست روزانه برای مطب

### 👨‍⚕️ برای مدیر کل
- **پزشکان:** افزودن/ویرایش/حذف پزشک، تخصیص کاربر وردپرس به عنوان پزشک/منشی
- **برنامه کاری:** تعریف برنامه هفتگی (شنبه تا جمعه) + تاریخ خاص (تعطیلی)، ساعت شروع/پایان، مدت هر اسلات
- **تولید اسلات:** تولید خودکار نوبت‌های قابل رزرو برای 30 روز آینده
- **خدمات:** تعریف خدمات پزشکی با قیمت (برای محاسبه خودکار)
- **اطلاعیه‌ها:** اطلاعیه عمومی یا برای پزشک خاص (مثلا: دکتر فلان روز نیست) - نمایش در صفحه رزرو
- **تنظیمات:** مبلغ بیعانه، اطلاعات کلینیک، سایز پرینتر حرارتی، فعال‌سازی ووکامرس

### 🛒 اتصال‌ها
- **ووکامرس:** اگر فعال باشد، برای هر رزرو سفارش ایجاد می‌شود و بیمار به درگاه پرداخت می‌رود. پس از پرداخت، وضعیت نوبت تایید می‌شود
- **المنتور:** 3 ویجت اختصاصی در دسته "نوبت دهی سینا":
  - لیست پزشکان
  - فرم رزرو نوبت
  - پیگیری نوبت

### 🖨️ پرینت حرارتی
- **80mm:** طراحی بهینه برای پرینترهای حرارتی (فاکتور زن)
- **A4:** رسید کامل با جدول خدمات و محل امضا
- **چاپ خودکار:** لینک `/sina-print/CODE/?autoprint=1` برای چاپ مستقیم
- **بارکد:** نمایش کد رهگیری به صورت بارکد متنی

## 📦 نصب

1. پوشه `sina-doctor-booking` را در `/wp-content/plugins/` آپلود کنید
2. از پیشخوان وردپرس افزونه را فعال کنید
3. جدول‌ها به صورت خودکار ساخته می‌شوند + 3 پزشک نمونه + برنامه کاری
4. برگه‌ها به صورت خودکار ساخته می‌شوند:
   - `/sina-booking/` - صفحه اصلی رزرو
   - `/sina-patient-panel/` - پنل بیمار
   - `/sina-secretary-panel/` - پنل منشی

### شورت‌کدها
```
[sina_booking]              // صفحه اصلی (همه پزشکان)
[sina_booking doctor_id=1]  // برای پزشک خاص
[sina_doctors_list columns=3]
[sina_patient_panel]
[sina_secretary_panel]
[sina_tracking]
```

## 🗄️ ساختار دیتابیس

- `wp_sina_doctors` - پزشکان
- `wp_sina_services` - خدمات و قیمت‌ها
- `wp_sina_schedules` - قالب برنامه هفتگی
- `wp_sina_slots` - اسلات‌های تولید شده (تاریخ + ساعت)
- `wp_sina_appointments` - نوبت‌های رزرو شده
- `wp_sina_announcements` - اطلاعیه‌ها

## 👥 نقش‌های کاربری

- `sina_doctor` - پزشک (می‌تواند نوبت‌های خود را ببیند)
- `sina_secretary` - منشی (مدیریت نوبت‌ها)
- `sina_patient` - بیمار
- مدیر کل دسترسی کامل دارد

## 🔧 تنظیمات پیشرفته

در پیشخوان > نوبت دهی > تنظیمات:
- مبلغ بیعانه رزرو
- فعال‌سازی ووکامرس
- نام، آدرس، تلفن کلینیک (برای چاپ)
- سایز کاغذ حرارتی (58mm / 80mm)

## 🎨 طراحی

- RTL کامل، فونت Vazirmatn
- UI مدرن با Tailwind-like، کارت‌های با سایه نرم
- ریسپانسیو: موبایل، تبلت، دسکتاپ
- انیمیشن‌های نرم، لودینگ اسپینر
- 5 مرحله‌ای: پزشک > روز > ساعت > اطلاعات > تایید

## 🔐 امنیت

- Nonce برای تمام درخواست‌های AJAX
- Capability check برای پنل منشی
- Sanitization تمام ورودی‌ها
- Tracking code یکتا و غیرقابل حدس

## 📱 سناریو کامل استفاده

1. **مدیر:** پزشکان را اضافه می‌کند، برنامه کاری شنبه تا چهارشنبه 9-13 تعریف می‌کند، خدمات (ویزیت 350k + نوار قلب 150k) را اضافه می‌کند، دکمه تولید اسلات 30 روز را می‌زند
2. **بیمار:** وارد `/sina-booking/` می‌شود، دکتر احمدی را انتخاب می‌کند، روز دوشنبه 15 مرداد (3 نوبت خالی) را می‌زند، ساعت 10:15 را انتخاب می‌کند، اطلاعات خود را پر می‌کند، 5,000 تومان پرداخت می‌کند (یا بدون پرداخت اگر ووکامرس غیرفعال باشد)، کد SINA-A1B2C3D4 می‌گیرد، رسید را چاپ می‌کند
3. **منشی:** وارد `/sina-secretary-panel/` می‌شود، لیست امروز را می‌بیند، بیمار که مراجعه کرد روی نوبت کلیک می‌کند، خدمات "نوار قلب" را تیک می‌زند، دکمه محاسبه را می‌زند (350k+150k=500k)، مبلغ پرداختی را وارد می‌کند، تاریخ ویزیت واقعی را ثبت می‌کند، وضعیت را "ویزیت شده" می‌کند، رسید نهایی را با پرینتر حرارتی چاپ می‌دهد
4. **اطلاعیه:** مدیر اطلاعیه می‌زند "دکتر احمدی پنجشنبه 1404/05/20 حضور ندارند" - در صفحه رزرو نمایش داده می‌شود
